# Python Multiple Choice Quiz Program

A lightweight terminal application written in Python that presents multiple-choice questions, validates user answers, and calculates a final score.

---

## Program Features

- **Interactive Terminal Quiz**: Displays questions and answer choices in a clean format.
- **Input Normalization**: Strips accidental whitespace and converts answers (e.g., lowercase `a`) into uppercase (`A`).
- **Real-Time Feedback**: Informs the user immediately whether their answer is correct or incorrect.
- **Final Score Summary**: Tracks correct responses and displays the total score at the end of the quiz.
